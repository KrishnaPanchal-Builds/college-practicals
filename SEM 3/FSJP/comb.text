A college wants to store student information. Create a Student class where one student object can be created with default values, another with user-provided values, and a third by copying an existing student record.

class Student {
    private int id;
    private String name;
    private String course;
    private double gpa;

    public Student() {
        this.id = 0;
        this.name = "Unknown";
        this.course = "General";
        this.gpa = 0.0;
    }

    public Student(int id, String name, String course, double gpa) {
        this.id = id;
        this.name = name;
        this.course = course;
        this.gpa = gpa;
    }

    public Student(Student other) {
        this.id = other.id;
        this.name = other.name;
        this.course = other.course;
        this.gpa = other.gpa;
    }

    public void display() {
        System.out.println("Student ID: " + id);
        System.out.println("Name      : " + name);
        System.out.println("Course    : " + course);
        System.out.println("GPA       : " + gpa);
        System.out.println("----------------------------------------");
    }
}

class StudentConstructorDemo {
    public static void main(String[] args) {
        System.out.println("--- Student Information Management ---\n");

        System.out.println("1. Student created with Default Constructor:");
        Student s1 = new Student();
        s1.display();

        System.out.println("2. Student created with Parameterized Constructor:");
        Student s2 = new Student(101, "Alice Johnson", "Computer Science", 9.2);
        s2.display();

        System.out.println("3. Student created with Copy Constructor (copy of Alice):");
        Student s3 = new Student(s2);
        s3.display();
    }
}

A construction company needs a system to calculate the area of different shapes used in building designs. Develop a Java program to calculate the area of a circle, rectangle, and triangle using the same method name.

class ShapeArea {
    double calculateArea(double radius) {
        return Math.PI * radius * radius;
    }

    double calculateArea(double length, double breadth) {
        return length * breadth;
    }

    double calculateArea(float base, float height) {
        return 0.5 * base * height;
    }

    double calculateArea(double a, double b, double c) {
        double s = (a + b + c) / 2.0;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));
    }
}

class MethodOverloadingDemo {
    public static void main(String[] args) {
        ShapeArea calculator = new ShapeArea();

        System.out.println("--- Construction Design Shape Area Calculator ---\n");

        double radius = 7.0;
        double circleArea = calculator.calculateArea(radius);
        System.out.printf("Area of Circle (radius = %.2f)            : %.2f%n", radius, circleArea);

        double length = 12.0;
        double breadth = 8.0;
        double rectArea = calculator.calculateArea(length, breadth);
        System.out.printf("Area of Rectangle (length = %.2f, breadth = %.2f): %.2f%n", length, breadth, rectArea);

        float base = 10.0f;
        float height = 6.0f;
        double triArea = calculator.calculateArea(base, height);
        System.out.printf("Area of Triangle (base = %.2f, height = %.2f)  : %.2f%n", base, height, triArea);

        double a = 3.0, b = 4.0, c = 5.0;
        double triHeronArea = calculator.calculateArea(a, b, c);
        System.out.printf("Area of Triangle (sides = %.1f, %.1f, %.1f)       : %.2f%n", a, b, c, triHeronArea);
    }
}

Different banks calculate interest using different rates. Design a program where each bank overrides a common method to display its applicable interest rate.

class Bank {
    protected String bankName;

    public Bank(String bankName) {
        this.bankName = bankName;
    }

    public double getInterestRate() {
        return 0.0;
    }

    public void displayInterestRate() {
        System.out.println("Bank: " + bankName + " | Applicable Interest Rate: " + getInterestRate() + "%");
    }

    public double calculateSimpleInterest(double principal, int years) {
        return (principal * getInterestRate() * years) / 100.0;
    }
}

class SBI extends Bank {
    public SBI() {
        super("State Bank of India (SBI)");
    }

    @Override
    public double getInterestRate() {
        return 6.50;
    }
}

class ICICI extends Bank {
    public ICICI() {
        super("ICICI Bank");
    }

    @Override
    public double getInterestRate() {
        return 7.00;
    }
}

class HDFC extends Bank {
    public HDFC() {
        super("HDFC Bank");
    }

    @Override
    public double getInterestRate() {
        return 7.25;
    }
}

class Axis extends Bank {
    public Axis() {
        super("Axis Bank");
    }

    @Override
    public double getInterestRate() {
        return 7.10;
    }
}

class MethodOverridingDemo {
    public static void main(String[] args) {
        System.out.println("--- Banking Interest Rates (Method Overriding & Runtime Polymorphism) ---\n");

        Bank[] banks = {
            new SBI(),
            new ICICI(),
            new HDFC(),
            new Axis()
        };

        double principal = 100000.0;
        int years = 3;

        System.out.printf("Sample Loan/Deposit Calculation for Principal: Rs. %.2f over %d years:%n%n", principal, years);

        for (Bank bank : banks) {
            bank.displayInterestRate();
            double interest = bank.calculateSimpleInterest(principal, years);
            System.out.printf("  -> Interest accrued for %d years: Rs. %.2f%n", years, interest);
            System.out.println("------------------------------------------------------------");
        }
    }
}

A smart device can perform both printing and scanning operations. Implement interfaces to represent these functionalities and demonstrate multiple inheritance through interfaces.

interface Printable {
    void printDocument(String documentName);
    void checkInkLevel();
}

interface Scannable {
    void scanDocument(String documentName);
    void saveScanToCloud(String fileName);
}

class SmartDevice implements Printable, Scannable {
    private String deviceId;
    private String modelName;
    private int inkLevelPercent;

    public SmartDevice(String deviceId, String modelName, int inkLevelPercent) {
        this.deviceId = deviceId;
        this.modelName = modelName;
        this.inkLevelPercent = inkLevelPercent;
    }

    @Override
    public void printDocument(String documentName) {
        if (inkLevelPercent < 5) {
            System.out.println("[" + modelName + "] Printing failed: Ink critically low (" + inkLevelPercent + "%).");
            return;
        }
        inkLevelPercent -= 2;
        System.out.println("[" + modelName + "] Printing document: '" + documentName + "' -> Complete. (Remaining ink: " + inkLevelPercent + "%)");
    }

    @Override
    public void checkInkLevel() {
        System.out.println("[" + modelName + "] Current Ink Level: " + inkLevelPercent + "%");
    }

    @Override
    public void scanDocument(String documentName) {
        System.out.println("[" + modelName + "] Scanning physical document: '" + documentName + "' at 600 DPI -> Scan successful.");
    }

    @Override
    public void saveScanToCloud(String fileName) {
        System.out.println("[" + modelName + "] Uploading scanned file '" + fileName + ".pdf' to secure cloud storage -> Done.");
    }

    public void displayDeviceInfo() {
        System.out.println("Device ID   : " + deviceId);
        System.out.println("Model Name  : " + modelName);
        System.out.println("Capabilities: Printing, Scanning, Cloud Sync");
        System.out.println("------------------------------------------------------------");
    }
}

class InterfaceDemo {
    public static void main(String[] args) {
        System.out.println("--- Smart All-In-One Device (Multiple Inheritance via Interfaces) ---\n");

        SmartDevice device = new SmartDevice("HP-ENVY-702", "HP Envy All-in-One Multifunction", 85);
        device.displayDeviceInfo();

        System.out.println(">> Operating device directly as SmartDevice:");
        device.printDocument("Annual_Financial_Report.pdf");
        device.scanDocument("Signed_Vendor_Contract.jpg");
        device.saveScanToCloud("Signed_Vendor_Contract");
        System.out.println();

        System.out.println(">> Accessing device via Printable interface reference:");
        Printable printerRef = device;
        printerRef.checkInkLevel();
        printerRef.printDocument("Lecture_Notes_Unit1.docx");
        System.out.println();

        System.out.println(">> Accessing device via Scannable interface reference:");
        Scannable scannerRef = device;
        scannerRef.scanDocument("National_Identity_Card.png");
        scannerRef.saveScanToCloud("Identity_Proof_Verification");
        System.out.println("------------------------------------------------------------");
    }
}

A bank account should not allow withdrawal amounts greater than the available balance. Develop a program that handles such invalid transactions using exception handling.

class InsufficientFundsException extends Exception {
    private double requestedAmount;
    private double currentBalance;

    public InsufficientFundsException(String message, double requestedAmount, double currentBalance) {
        super(message);
        this.requestedAmount = requestedAmount;
        this.currentBalance = currentBalance;
    }

    public double getDeficit() {
        return requestedAmount - currentBalance;
    }

    public double getRequestedAmount() {
        return requestedAmount;
    }

    public double getCurrentBalance() {
        return currentBalance;
    }
}

class BankAccount {
    private String accountNumber;
    private String accountHolder;
    private double balance;

    public BankAccount(String accountNumber, String accountHolder, double initialBalance) {
        this.accountNumber = accountNumber;
        this.accountHolder = accountHolder;
        this.balance = Math.max(0.0, initialBalance);
    }

    public void deposit(double amount) {
        if (amount <= 0) {
            System.out.println("Invalid deposit amount! Amount must be positive.");
            return;
        }
        balance += amount;
        System.out.printf("Deposited: Rs. %.2f | Updated Balance: Rs. %.2f%n", amount, balance);
    }

    public void withdraw(double amount) throws InsufficientFundsException {
        System.out.printf("Attempting to withdraw: Rs. %.2f...%n", amount);

        if (amount <= 0) {
            System.out.println("Invalid transaction: Withdrawal amount must be greater than 0.");
            return;
        }

        if (amount > balance) {
            throw new InsufficientFundsException(
                "Transaction Declined: Insufficient balance in account.",
                amount,
                balance
            );
        }

        balance -= amount;
        System.out.printf("Withdrawal Successful: Rs. %.2f deducted. Remaining Balance: Rs. %.2f%n", amount, balance);
    }

    public void displaySummary() {
        System.out.println("----------------------------------------");
        System.out.println("Account Number : " + accountNumber);
        System.out.println("Account Holder : " + accountHolder);
        System.out.printf("Current Balance: Rs. %.2f%n", balance);
        System.out.println("----------------------------------------");
    }
}

class ExceptionHandlingDemo {
    public static void main(String[] args) {
        System.out.println("--- Bank Account Transaction System (Exception Handling) ---\n");

        BankAccount account = new BankAccount("SBIN-00984512", "Pankaj Sharma", 15000.00);
        account.displaySummary();

        System.out.println("1. Performing Deposit:");
        account.deposit(5000.00);
        System.out.println();

        System.out.println("2. Performing Valid Withdrawal:");
        try {
            account.withdraw(8000.00);
        } catch (InsufficientFundsException e) {
            System.out.println("Exception caught: " + e.getMessage());
        }
        System.out.println();

        System.out.println("3. Attempting Invalid Withdrawal Exceeding Balance:");
        try {
            account.withdraw(20000.00);
        } catch (InsufficientFundsException e) {
            System.out.println("[CAUGHT EXCEPTION] " + e.getMessage());
            System.out.printf("  Requested Amount : Rs. %.2f%n", e.getRequestedAmount());
            System.out.printf("  Available Balance: Rs. %.2f%n", e.getCurrentBalance());
            System.out.printf("  Shortage/Deficit : Rs. %.2f%n", e.getDeficit());
        } finally {
            System.out.println("Transaction check completed.");
        }
        System.out.println();

        System.out.println("Final Account State:");
        account.displaySummary();
    }
}
