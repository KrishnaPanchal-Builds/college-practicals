## How to Execute the Programs (Step-by-Step from Terminal)

### Prerequisites
Open your terminal (Command Prompt, PowerShell, or Bash) and navigate to the folder:
```bash
cd "SEM 3/FSJP"
```

### Program 01: Constructors (`01.java`)
1. **Create / Open the file:**
   ```bash
   notepad 01.java
   ```
2. **Compile the program:**
   ```bash
   javac 01.java
   ```
3. **Run the program:**

## Detailed Programs

### [Student Constructors](./01.java)
- **Direct Link:** [`01.java`](./01.java)
- **Objective:** Create a Student class where one student object can be created with default values, another with user-provided values, and a third by copying an existing student record.

### [Shape Area Method Overloading](./02.java)
- **Direct Link:** [`02.java`](./02.java)
- **Objective:** Develop a Java program to calculate the area of a circle, rectangle, and triangle using the same method name (method overloading).

### [Product Constructor Overloading](./03.java)
- **Direct Link:** [`03.java`](./03.java)
- **Objective:** Maintain mobile store product records where some products are registered with only a name, while others include name and price, using constructor overloading.

### [University Records Single Inheritance](./04.java)
- **Direct Link:** [`04.java`](./04.java)
- **Objective:** Develop a program using single inheritance to reuse person details for student records.

### [Postgraduate Student Multilevel Inheritance](./05.java)
- **Direct Link:** [`05.java`](./05.java)
- **Objective:** Design a program using multilevel inheritance to represent an educational institution hierarchy (Person -> Student -> PostgraduateStudent).

### [Company Employee Hierarchical Inheritance](./06.java)
- **Direct Link:** [`06.java`](./06.java)
- **Objective:** Implement hierarchical inheritance to store company employee information for Managers and Developers sharing common employee details.

### [Bank Interest Rates Method Overriding](./07.java)
- **Direct Link:** [`07.java`](./07.java)
- **Objective:** Design a program where different banks override a common method to display applicable interest rates using dynamic method dispatch.

### [Smart Device Multiple Inheritance Interface](./08.java)
- **Direct Link:** [`08.java`](./08.java)
- **Objective:** Implement Printable and Scannable interfaces to represent smart device functionalities and demonstrate multiple inheritance through interfaces.

### [Bank Account Exception Handling](./09.java)
- **Direct Link:** [`09.java`](./09.java)
- **Objective:** Develop a bank account program that handles invalid withdrawal transactions exceeding the available balance using custom exception handling.

### [Railway Reservation Multithreading](./10.java)
- **Direct Link:** [`10.java`](./10.java)
- **Objective:** Implement a railway reservation system performing simultaneous ticket booking and ticket cancellation using multiple threads.

### [Email Subscription Validation](./11.java)
- **Direct Link:** [`11.java`](./11.java)
- **Objective:** Validate subscriber email addresses using regular expressions before accepting online newsletter subscription requests.

### [Display Current Date and Time](./12.html)
- **Direct Link:** [`12.html`](./12.html)
- **Objective:** Display the current date and time whenever the webpage loads using JavaScript and DOM manipulation.

### [Display Welcome Message](./13.html)
- **Direct Link:** [`13.html`](./13.html)
- **Objective:** Display a personalized welcome message on the webpage upon clicking a button using JavaScript DOM manipulation.

### [Background Color Changer](./14.html)
- **Direct Link:** [`14.html`](./14.html)
- **Objective:** Automatically change the webpage background color every five seconds using JavaScript DOM and timing events.

### [React Hooks Color Selector](./15.html)
- **Direct Link:** [`15.html`](./15.html)
- **Objective:** Implement a React component using React Hooks (`useState`) with four buttons (Red, Blue, Green, Yellow) that displays the selected color message.
