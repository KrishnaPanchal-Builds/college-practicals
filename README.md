# college-practicals

Repository containing college laboratory practicals and coursework implementations.

## Course Structure

### [Semester 3](./SEM%203)

- **[COA - Computer Organization and Architecture](./SEM%203/COA)**: Includes base conversions, 1's and 2's complement, Booth's multiplication, Restoring division, and 8086 assembly language programs.
- **[AOA - Analysis of Algorithms](./SEM%203/AOA)**: Includes sorting algorithms, divide-and-conquer techniques, greedy strategies, and backtracking implementations.
- **[FSJP - Fundamentals of Java Programming](./SEM%203/FSJP)**: Includes constructors, method overloading, constructor overloading, single inheritance, multilevel inheritance, hierarchical inheritance, method overriding, interfaces, and exception handling.
